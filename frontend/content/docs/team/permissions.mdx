Fine-tune what team members can access in your workspace.

## Permission categories

- Projects — Create, edit, view
- Clients — Add, edit, view
- Invoices — Create, send, view
- Settings — Full access or restricted

## How to set permissions

1. Go to Team → Permissions
2. Select a role
3. Toggle permissions on/off
4. Save changes

## Custom permissions

- Create custom roles for specific needs
- Assign different permissions per project
- Override role defaults for individuals

> Business Tip: Use the principle of least privilege. Give team members only the access they need to do their job.
