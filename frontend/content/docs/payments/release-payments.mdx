Release escrowed funds when milestones are completed and approved.

## How payments release

1. Milestone deliverables are submitted
2. Client reviews and approves
3. Funds are released from escrow
4. Payment is sent to your wallet

## Automatic release

- Enable Auto-Release on milestones
- Funds release after a set number of days
- Client can still approve early

## Manual release

1. Go to Project → Milestones
2. Select the approved milestone
3. Click Release Payment

> Business Tip: Set clear acceptance criteria before starting work. It prevents disputes and ensures smooth payment release.
