Milestones help you break projects into manageable chunks with clear deliverables and payment triggers.

## Why use milestones

- **Track progress** — See exactly where each project stands
- **Trigger payments** — Release escrow funds on approval
- **Set expectations** — Clear deliverables and deadlines
- **Build trust** — Clients know what they're paying for

## Creating milestones

1. Open a project
2. Click **Add Milestone**
3. Enter the milestone details
4. Set the amount and due date
5. Save the milestone

## Milestone details

- **Title** — Clear description of the deliverable
- **Amount** — Payment for this milestone
- **Due Date** — When the deliverable is expected
- **Description** — Detailed scope of work

> **Business Tip:** Keep milestones small and frequent. This maintains momentum and improves cash flow.

## Approval flow

1. You mark a milestone as complete
2. The client reviews the deliverable
3. The client approves or requests changes
4. On approval, funds release from escrow
5. An invoice is generated automatically

> **Business Tip:** Always get milestone approval in writing. The client portal makes this seamless.
