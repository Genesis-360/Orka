Share files, documents, and assets within your projects.

## How to upload files

1. Open a project
2. Go to **Files**
3. Click **Upload**
4. Select files from your device

## File organization

- Create folders to organize files
- Tag files by type (design, document, code)
- Search across all project files

## Sharing with clients

- Toggle **Share with Client** on any file
- Clients see shared files in their portal
- Control access per file or folder

> **Business Tip:** Keep project files organized from the start. It saves time when you need to find something later.
