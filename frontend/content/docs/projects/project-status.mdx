Monitor project progress and identify issues early.

## Project statuses

- Planning — Project is being set up
- In Progress — Active work is happening
- On Hold — Paused, waiting for client input
- Review — Deliverables submitted for approval
- Completed — All milestones delivered and paid

## How to update status

1. Open a project
2. Click the status dropdown
3. Select the new status

## Health indicators

- On Track — Milestones are on schedule
- At Risk — Some milestones are behind
- Off Track — Multiple milestones are delayed

> Business Tip: Check project health weekly. Early detection of delays helps you communicate with clients before problems escalate.
