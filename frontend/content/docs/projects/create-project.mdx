Projects are where you manage deliverables, milestones, and payments for client work.

## Creating a project

1. Click Projects in the sidebar
2. Click Create Project
3. Fill in the project details
4. Define milestones and deliverables
5. Set up escrow (optional)

## Project details

- Project Name — A clear, descriptive name
- Client — Select the client this project is for
- Budget — Total project budget
- Timeline — Start and end dates
- Description — Brief project scope

> Business Tip: Write a clear project scope upfront. This prevents misunderstandings and scope creep later.

## Milestones

Break your project into milestones:

- Each milestone has a deliverable, due date, and amount
- Milestones track progress and trigger payments
- Clients approve milestones before funds are released

## Files and collaboration

- Upload files directly to the project
- Share files with clients through the portal
- Track all activity in the feed

> Business Tip: Use project templates for recurring work. This saves time and ensures consistency.
