Customize how Orka works for your team.

## Preference categories

- **Language** — Interface language
- **Timezone** — Your team's timezone
- **Date format** — How dates display
- **Currency** — Default currency for invoices

## How to update preferences

1. Go to **Workspace Settings**
2. Click **Preferences**
3. Update your settings
4. Save changes

## Team-wide settings

- Preferences apply to all team members
- Individual users can override some settings
- Admin can lock certain preferences

> **Business Tip:** Set preferences once during setup. They apply to all new projects and invoices.
