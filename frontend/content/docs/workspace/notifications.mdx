Stay informed about important events without being overwhelmed.

## Notification types

- **Project updates** — Milestones, deliverables, status changes
- **Invoice activity** — Sent, viewed, paid
- **Team activity** — Member changes, approvals
- **Client activity** — Portal visits, messages

## How to configure

1. Go to **Workspace Settings**
2. Click **Notifications**
3. Toggle each notification type
4. Set delivery method (email, in-app, both)

## Quiet hours

- Set hours when notifications pause
- Still delivered in-app
- Resume at your chosen time

> **Business Tip:** Enable only the notifications you need. Too many notifications reduce productivity.
