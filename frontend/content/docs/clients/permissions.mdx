Control what clients can access in the client portal.

## Permission levels

- Full access — See all projects, invoices, and files
- Limited access — See only assigned projects
- Invoice only — See only invoices and payments

## How to set permissions

1. Go to Clients
2. Select a client
3. Click Portal Settings
4. Choose the permission level

## What each level can do

| Action | Full | Limited | Invoice Only |
|---|---|---|---|
| View projects | ✅ | ✅ (assigned) | ❌ |
| View invoices | ✅ | ✅ | ✅ |
| View files | ✅ | ✅ (assigned) | ❌ |
| Approve milestones | ✅ | ✅ | ❌ |

> Business Tip: Start with limited access and expand as trust builds. It protects your workspace while keeping clients informed.
