Secure your API requests with token-based authentication.

## Getting an API key

1. Go to Workspace Settings
2. Click API Keys
3. Click Generate New Key
4. Copy and save your key securely

## Using the key

Add the key to your requests:

```
Authorization: Bearer YOUR_API_KEY
```

## Key management

- Rotate keys regularly
- Revoke compromised keys
- Use different keys per environment

## Security best practices

- Never expose keys in client-side code
- Store keys in environment variables
- Use the minimum required permissions

> Business Tip: Rotate your API keys every 90 days. It's a simple security practice that protects your workspace.
