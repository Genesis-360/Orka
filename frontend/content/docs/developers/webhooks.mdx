Receive real-time notifications when events happen in Orka.

## Available events

- `project.created` — New project added
- `project.completed` — Project marked complete
- `invoice.paid` — Payment received
- `milestone.approved` — Milestone approved

## Setting up webhooks

1. Go to **Workspace Settings**
2. Click **Webhooks**
3. Enter your endpoint URL
4. Select events to listen for

## Payload format

```json
{
  "event": "invoice.paid",
  "timestamp": "2025-01-15T10:00:00Z",
  "data": {
    "invoiceId": "inv-123",
    "amount": 5000
  }
}
```

## Verifying webhooks

- Check the `X-Orka-Signature` header
- Validate the payload signature
- Reject unsigned requests

> **Business Tip:** Always verify webhook signatures. It prevents malicious actors from sending fake events.
